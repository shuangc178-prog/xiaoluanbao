# 「异世界之旅」卡面模板特征规格

> 基准样本：`isekai/isekai_001_unicorn/card_full.jpg`（R 卡「独角兽」，1086×1448，3:4）。
> 用途：生成同模板新卡时的对照基准与提示词底稿。提取日期 2026-09-19。

## 一、画幅与整体气质

- 竖版 **3:4**，渲染稿自带米白背景与柔和投影（进 APK 前仍要走 `prepare_art.py` 去背裁边）。
- 风格：**复古像素画（8/16-bit）× 暖色奶油系集换式卡牌**，表面覆盖细纸纹做旧质感。
- 配色与 App 的 Claude 主题同源：米白底 + 陶土橙强调。

## 二、版式结构（自上而下）

1. **四角像素装饰**：奶油底四角各有橙色小方块斜阵（6×6 + 两粒 4×4）+ 一枚小十字星，四角对称。R 档仅此装饰，最简。
2. **外框**：陶土橙粗圆角描边（圆角约 22/1086 宽），框内侧有一圈细米白线，再进奶油底。
3. **拱形插画窗**：占上半约 55%，顶部圆拱、下缘平直。场景分层（后→前）：
   - 粉橙渐变天空 + 奶油色像素月亮（右上）+ 白云（左上、右中）+ 橙色小十字星散落；
   - 远景陶土色小城堡（右侧，主塔 + 双副塔 + 旗子）；
   - 粉褐色远山剪影 → 草绿色草地，点缀白/粉色小黄花；
   - 主体角色（本卡：白色独角兽跃起，金角、粉鬃粉尾、闭眼笑、黑描边）；
   - **橙色像素主角「小卵包」必出场**（本卡骑在独角兽背上）——整套卡的设计母题，不是画错。
4. **卡名**：大号加粗近黑字（笔画带像素阶梯感的衬线味），居中，字距拉开。
5. **系列副题**：「— 异世界之旅 —」陶土橙小字，两侧短横线。
6. **胶囊标签**：浅橙底圆角胶囊，内为深陶土字「旅程启程」，左右各一枚四角星 ✦。本套五张文案相同。
7. **稀有度徽章**：像素锯齿边圆形（陶土橙实心），内一个奶油色衬线字母「R」。
8. **散点与肌理**：卡名两侧、徽章两侧各有一枚小十字星；全卡细纸纹。

## 三、配色（近似取值）

| 用色 | 值 | 说明 |
|---|---|---|
| 米白底 | `#F7F0E4` | 卡面基底（同源 App `#FAF9F5`） |
| 陶土橙 | `#C96A42` | 外框 / 徽章 / 装饰 / 副题（同源 App `#C6613F`） |
| 粉橙天空 | `#F1AF87` → `#F5C9A2` | 插画窗天空，可随卡主题换 |
| 草绿 | `#7C9A62` / `#5E7F4E` | 草地双色 |
| 鬃毛粉 | `#F2B8C6` | 角色点缀色 |
| 近黑文字 | `#2E2A26` | 卡名 |
| 胶囊底 | `#F6DFC8` | 标签底，字 `#A8552F` |
| 月亮/云 | `#FBEED3` / `#FBF3E4` | 奶油色天体 |

生成新卡时：**底 / 框 / 文字三色固定，场景色可随卡的主题微调**。

## 四、不变项 vs 可变项

| | 内容 |
|---|---|
| 模板不变 | 3:4 画幅、外框 + 细米白线、四角像素装饰、拱形插画窗、版式顺序（名→副题→胶囊→徽章）、胶囊文案「旅程启程」、十字星点缀、纸纹 |
| 每卡可变 | 插画主体与场景、卡名、稀有度字母、该档边框装饰、场景配色微调 |

## 五、稀有度档位差异（本套 5 档，来自各卡 meta 档案）

R 四角装饰块（**本基准，最简**）→ SR 描金树叶 → SSR 月桂与王冠 → SSSR 紫色蝠翼 → XR 罗盘星与云纹。
徽章字母随档位：R / SR / SSR / SSSR / XR（**没有 UR，写法照设计稿**）。

## 六、生成提示词底稿（ImageGen 用，【】内按新卡替换）

> 复古像素风集换式卡牌，竖版 3:4。米白色卡底带细纸纹，陶土橙色粗圆角描边外框，框内侧一圈细米白线，卡面四角有橙色像素小方块与十字星装饰。上半部为拱顶像素画场景：【场景描述】，画面主体是【主体描述】，橙色像素小生物「小卵包」【出场方式：骑在背上/站在脚边/仰头看……】。下半部居中排：大号加粗近黑色卡名「【卡名】」；陶土橙小字「— 异世界之旅 —」两侧带短横线；浅橙底圆角胶囊「✦ 旅程启程 ✦」；像素锯齿边圆形徽章内一个奶油色字母「【稀有度】」。卡名与徽章两侧散落小十字星。

## 七、进 App 的落地提醒（生成之后必做）

1. 成图存 `.workbuddy/cards/isekai/isekai_00N_<短名>/card_full.jpg`，复制同系列 `meta.json` 改写。
2. `cards.json` 对应系列 `cards[]` 加一条；若进 App 还要加 `data/card/CardModels.kt` 枚举项（**id 两处一致**）。
3. 跑 `python .workbuddy/cards/prepare_art.py` 去背裁边 → `python .workbuddy/cards/sync_cards.py` 对账。
4. 卡面宽高比写死在代码里，新图必须保持 3:4。
