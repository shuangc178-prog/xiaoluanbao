## 2. 安全与权限核查

**Manifest（5 项权限，均有明确用途）**：`INTERNET`（天气在线接口）、`ACCESS_COARSE_LOCATION`（天气定位）、`POST_NOTIFICATIONS`、`SCHEDULE_EXACT_ALARM`、`RECEIVE_BOOT_COMPLETED`。
`ReminderReceiver` 为 `exported=false`（显式 PendingIntent 专用）；`ReminderRestoreReceiver` 接 BOOT / MY_PACKAGE_REPLACED / 精确闹钟授权变化三条广播，符合第 16.13 节口径。

**WebView（学习阅读器）**：JS 已开启（仅目录锚点定位），但 `allowFileAccess` / `allowContentAccess` / `allowFileAccessFromFileURLs` / `allowUniversalAccessFromFileURLs` 全部为 false，`blockNetworkLoads=true`、mixed content 禁止、DOM storage 与 database 关闭；本地资源经 `WebViewAssetLoader` 挂载。边界完整。

**导入侧（StudyImporter）**：ZIP 条目路径穿越校验（canonicalPath 前缀比对）、文件名清洗与截断、512 MB / 5000 条预算、树深 32 限制、重复按 SHA-256 去重、删除快照限制在 `study_imports` 根内。设计到位，但**这些校验全是 private 且无单测**（见第 3 节）。

## 3. 测试覆盖缺口（按优先级）

| 级别 | 缺口 | 说明与建议 |
|---|---|---|
| P1 | `sanitizeSourceMarkup` 无测试且 private | 安全清洗（script/iframe 剥离、事件处理器、`javascript:` URL）全靠 4 条正则，是回归风险最高的一块。建议改 `internal` 并补 `StudySanitizeTest`（含未闭合标签、大小写、嵌套引号等对抗样本） |
| P1 | `StudyImporter` 纯逻辑不可单测 | `safeZipTarget` / `safeFileName` / `ImportBudget` / 标题提取与 `Context` 强耦合。建议抽 `internal` 纯函数后补路径穿越、预算上限、同名去重用例 |

## 4. 发现项（需产品决策，未擅改代码）

1. **空任务下不能开始打卡（已确认设计意图，门禁已补全）**：原行为允许空任务「开始打卡」，但结束门禁（勾完全部任务）永远不满足，当天卡在红色。经确认属有意设计——防止「没做任务却打卡」的错误统计。已补全开始侧：空任务时按钮禁用并提示「添加今天的任务后可打卡」（按钮 + 点击回调双保险）；当天中途删光任务需补任务才能结束，次日 6 点换日自动复位，遗留「有始无终」记录 `isCompleted=false` 不进累计与连续。口径已写入产品文档第 16.16 节。后续按产品决策进一步扩展打卡口径：**完成全部任务但忘记点结束的，换日自动补记为已打卡**，「未打卡」只剩「当天没结束打卡且任务没勾完」与「当天没安排任务」两种，详见产品文档第 16.17 节与新增的 10 个口径用例。
2. **文档 16.10 与代码不一致**：统计页已不再订阅日记与学习资料（`StatsController` 仅收打卡记录与计划；`StatsSections` 无日记/学习卡片；日详情弹层无日记条数）。**后续状态：已在 2026-09-20 按当前代码更正文档。**
3. **Release 未签名**：`build.gradle.kts` 当时无 `signingConfig`，产物为 `app-release-unsigned.apk`。**后续状态：已接入本机属性文件与 keystore 的签名配置，并产出 `app-release.apk`；密钥材料不进入 Git。**
4. **备份隐私边界**：`allowBackup="true"` 且未声明 `dataExtractionRules`，Android 12+ 云备份/设备迁移会包含全部 DataStore（含日记）。与文档 9.3「本地访问保护、设备内数据保护、备份保护分别设计」的要求尚有距离，建议显式声明提取规则。
5. 6 处 WebView deprecated 警告；versionCode=1 / versionName=0.1.0 对首个发布版成立，后续注意递增。
