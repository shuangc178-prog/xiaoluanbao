# 统计图表与奖励入口

## 行为

- 统计页新增近 7 天每日学习总时长柱状图，固定为当前打卡日及前六天，按日期升序。
  没有计划的日期显示零时长；打卡起止时间、休息卡补记不会生成学习时间。
- 点击整列或日期均打开该日任务用时弹层，包括零时长日期；关闭后主页面保留所选日。
  历史日期选择和「回到今天」继续有效，选择历史日期不移动七天窗口。
- 删除「当天打卡」气泡。任务横柱只绘制实际时长对应的实心部分，不再绘制后方空轨道。
  长短任务仍使用相同比例尺，任务状态和具体用时继续显示。
- 本日计划的「休息卡」「卡片收集」是带图案和文字标签的小按钮，点击打开可滚动弹层。
  休息卡弹层可选择过去的日期补记，卡册弹层保留两弹卡面、卡片详情、兑换确认和兑换结果。
  补记日期与统计页历史选择分别保存。
- 两种学习柱状图共用 850ms 的平滑增长动画：初次出现或切换明细日期从零开始；
  实时计时更新从当前值衔接。动画遵守系统动画时长设置。
- 图案按钮至少高 56dp；每个日期列至少宽 48dp，大字体下增加宽度并允许横向滚动。
  日期列具有按钮角色和选中状态，读屏提供完整日期与精确时长；任务信息按行合并朗读。
  弹层支持关闭按钮、返回键和系统的下滑关闭。

## 用户手动验收

按项目要求，界面、动画与真机交互由用户验证；本次不启动软件或截图。

1. 打开统计页，确认没有「当天打卡」、休息卡或卡册气泡，七天图包含今天与前六天。
2. 点击有学习时长的日期柱，确认弹层中的日期、任务顺序、各任务时长和当天总时长一致；
   点击零时长日期，确认可以查看未计时任务或空计划提示。
3. 查看一长一短两个任务，确认短任务柱体完全填色、后方没有灰色空轨道。
4. 切换统计页、选择另一历史日期、打开任务明细，观察横柱和竖柱从零增长。
   保持一个任务计时并停留在统计页，确认数值持续更新，柱体不每秒清零。
5. 在本日计划点击两个图案按钮；确认关闭后恢复紧凑入口，长内容可滚动。
   有可用休息卡时选择过去未打卡日期补记，确认库存减少且学习时长不变；
   已打卡或已补记日期不能再次使用。没有卡时使用按钮禁用。
6. 打开卡片收集，检查两弹卡面、卡片详情和兑换确认；具备资格时兑换，检查结果和新增休息卡库存。
7. 在明暗主题、较小屏幕及系统大字体下检查文本与点击；必要时左右滑动七天图查看其余日期。
   使用 TalkBack 检查日期、精确时长、选中状态、图案按钮名称及关闭操作；关闭系统动画后确认立即呈现最终值。
